
# Learnify — Online Learning Platform

A responsive landing page for a fictional online learning platform.
Created as a web development practice project for the Oasis Infobyte
Web Development Internship, Level 1.

## Features

- Navigation bar with section links
- Hero section with call-to-action buttons
- Course cards for Web Development, Python, and AI
- Learning benefits section
- Inspirational quotes section
- Call-to-action section and footer
- CSS hover effects and smooth scrolling
- Responsive layout for desktop, tablet, and mobile
- Semantic HTML5 and custom CSS styling

## Technologies Used

- HTML5
- CSS3
- CSS Grid and Flexbox
- Media queries

## How to Run

1. Download or clone this project.
2. Open the project folder in Visual Studio Code.
3. Open index.html in a browser, or use the Live Server extension.

## Note

Learnify is a fictional learning platform created for educational
and portfolio purposes. Course links are demonstration links,
not a real course-enrolment system.
